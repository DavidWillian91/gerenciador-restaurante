# Gerenciador de Restaurantes

Sistema em Python para cadastro, listagem e gerenciamento de restaurantes via terminal.

## Funcionalidades

- Cadastro de novos restaurantes
- Listagem de restaurantes cadastrados
- Ativação e desativação de restaurantes
- Interface interativa via terminal

## Tecnologias utilizadas

- Python 3
- Execução via terminal/console
